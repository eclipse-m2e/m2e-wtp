# Contributing to m2e-wtp

If you are interested in contributing to m2e-wtp, you can do so as follows:

- Try snapshots from https://download.eclipse.org/technology/m2e/m2e-wtp/updates/nightly/latest.
- Report issues to this repository.
- Submit Pull Requests. Please note that all contributors need to sign the [Eclipse Contributor Agreement](https://www.eclipse.org/legal/ECA.php).

See also https://github.com/jbosstools/m2e-wtp-tests which contains some additional integration tests.
